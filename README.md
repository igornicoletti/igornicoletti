I am a passionate software developer focused on creating production-ready web applications with an emphasis on performance, scalability, and modern architecture. My goal is to transform complex requirements into elegant, type-safe, and maintainable solutions using the latest industry standards.

### 🚀 My Stack and Development Philosophy

I believe in using the right tools to build efficient products. My current development environment is heavily influenced by "bleeding edge" technologies and strictly typed patterns:

### 🛠️ Core Technologies
* **Frontend:** React 19, TypeScript 5.9, Vite 7
* **Backend & Auth:** Supabase (Auth, DB, Realtime)
* **UI & Styling:** Tailwind CSS v4, shadcn/ui, Radix UI, and Motion for animations.
* **Routing:** React Router v7 (utilizing data APIs, loaders, and guards).
* **Testing:** Vitest and Testing Library (Unit & Integration).

### 🏛️ Architecture and Patterns
* **Module-Based Architecture:** I structure projects by domain/features (e.g., `/modules/auth`, `/modules/dashboard`) rather than technical layers, ensuring scalability and ease of maintenance.
* **Strict Type Safety:** I leverage TypeScript in Strict Mode combined with **Zod v4** for runtime validation (schemas), ensuring end-to-end type safety from the API to the UI.
* **Robust Forms:** Usage of **React Hook Form** integrated with Zod resolvers for manageable and performant form state.
* **Service Layer Pattern:** Abstracting API calls and business logic into dedicated service files to keep components clean and focused on UI.

### ✅ Quality and Tooling
* **Code Quality:** ESLint v9 with strict configurations and Prettier to maintain consistent code style.
* **Developer Experience:** pnpm for fast package management and strict environment variable typing.
